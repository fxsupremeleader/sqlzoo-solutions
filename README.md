Welcome to my SQL practice repository! This repository documents my journey of mastering SQL through [SQLZoo](https://sqlzoo.net/), covering fundamental queries to advanced relational database concepts.

* **Language:** SQL (PostgreSQL / MySQL / T-SQL)
* **Platform:** SQLZoo

## 💡 Key Concepts Practiced
As I work through these exercises, I am strengthening my skills in:
* **Data Retrieval:** Using `SELECT`, `WHERE`, `ORDER BY`, and `LIMIT`.
* **Aggregation:** Grouping data and filtering with `GROUP BY` and `HAVING`.
* **Relational Logic:** Connecting tables using `INNER JOIN`, `LEFT JOIN`, and `RIGHT JOIN`.
* **Advanced Queries:** Writing nested queries (`subqueries`) and handling `NULL` values.
